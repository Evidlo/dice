Dice Notation

Use standard dice notation to roll dice:

  • NdX - Roll N dice with X sides (e.g., 2d6 = two 6-sided dice)
  • +/- modifiers - Add or subtract values (e.g., 1d20+5)
  • d% - Percentile dice (1-100)
  • NdXkH/kL - Keep highest/lowest (e.g., 4d6kh3 = roll 4d6, keep 3 highest)
Complete list of features is here.

Examples:
  • 1d20 - Standard attack roll
  • 2d6+3 - Damage roll with modifier
  • 4d6kh3 - Ability score roll (drop lowest)
  • 1d100 or d% - Percentile roll
