  ## JavaScript Logic (app.js)                                                  
                                                                                
  ### Data Structure                                                            
  ```javascript                                                                 
  let diceEntries = []; // Array of {id, label, notation}                       
  ```                                                                           
                                                                                
  ### Functions                                                                 
  1. `addEntry(label, notation)` - Add new dice entry                           
  2. `removeEntry(id)` - Remove dice entry by id                                
  3. `rollDice(id)` - Roll dice for entry, show loading bar 0.5s, then          
  results                                                                       
  4. `renderEntries()` - Render all entries to DOM                              
  5. `openHelpModal()` / `closeHelpModal()` - Modal controls

  ## Help Modal Content                                                         
  Concise explanation of dice notation:                                         
  - `NdX` - Roll N dice with X sides (e.g., 2d6 = two 6-sided dice)             
  - `+/-` modifiers (e.g., 1d20+5)                                              
  - `d%` - Percentile (1-100)                                                   
  - Common examples: 1d20, 2d6+3, 4d6, 1d100
